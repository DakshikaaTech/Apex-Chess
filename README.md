# Apex-Chess
I have built a chess analysis website to help Chess Masters train their moves and analyze their games without worrying about subscriptions, ads and any other form of distraction.

<img width="939" height="507" alt="Apex chess" src="https://github.com/user-attachments/assets/37ba0f1a-7837-41f7-9698-5afde76c4cc7" />
You can try it out: https://dakshikaatech.github.io/Apex-Chess/

## Features include:
- A chessboard with all movable pieces.
- "Reset board" button which will change the board back to its starting position.
- "clear board" button which will remove all the pieces from the board.
- Annotations to record all the moves.
- Board FEN acts as a standard, single-line text format to record a specific position on a chessboard.
- Stockfish engine evaluation
- 3 Tactics puzzles (Hope you get them right!)
